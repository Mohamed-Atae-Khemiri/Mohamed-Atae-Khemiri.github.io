A free, step-by-step networking course for beginners who want to move into cybersecurity. It has 10 modules. Every module has theory, **figures**, **worked examples with sample output**, a hands-on lab and review questions with answers.

## How to use this course

- Study one module per week (5 to 8 hours): read, repeat each example yourself, do the lab, then answer the review questions without looking.
- Install **Wireshark**, **Cisco Packet Tracer** (free) and use a Linux machine (Kali or Ubuntu) for the command-line labs.
- Only practice scanning and packet capture on your own network or lab environments.


> Sample outputs in this course are examples. Your IP addresses, MAC addresses and timings will be different, and that is normal.
{: .prompt-warning }

## Modules

1. Network fundamentals
2. The OSI and TCP/IP models
3. Ethernet, MAC addresses, switching and VLANs
4. IP addressing and subnetting
5. Routing
6. Transport layer: TCP and UDP
7. Core application protocols (DNS, DHCP, HTTP)
8. NAT, firewalls, VPN and proxies
9. Wireless networking
10. Network security fundamentals
11. Final project and review questions

## 10-week study plan

| Week | Module | Hands-on |
|---|---|---|
| 1 | Fundamentals | map your home network |
| 2 | OSI / TCP-IP | first Wireshark capture |
| 3 | Ethernet, switching, VLANs | Packet Tracer VLAN lab |
| 4 | IP addressing, subnetting | 20 subnetting exercises |
| 5 | Routing | static and OSPF lab |
| 6 | TCP / UDP | capture a handshake |
| 7 | Application protocols | DNS and DHCP captures |
| 8 | NAT, firewalls, VPN | ACL lab, set up WireGuard |
| 9 | Wireless | audit your own Wi-Fi settings |
| 10 | Security and review | final project |

## Tools you will use

| Tool | Use |
|---|---|
| Wireshark / tcpdump | capture and analyze packets |
| Nmap | discover hosts and open ports (own network or authorized labs only) |
| ping, traceroute, nslookup, dig | basic diagnostics |
| netstat / ss | list connections and listening ports |
| Packet Tracer / GNS3 | build virtual networks |
| Netcat | test connections and ports |

## Certifications to aim for

CompTIA **Network+** first, then **Security+**, then Cisco **CCNA**. These fit well before offensive-security certifications.
